Before you start

You do not need to edit the website, install an SEO plugin, or give an agent your passwords. You only need the Google account connected to the business and a Microsoft account for Bing.

Already done

HTTPS, redirects to the preferred domain, crawlable pages, unique titles and descriptions, canonical links, robots.txt, and a nine-page sitemap are live.

The agent is doing

Technical redirect signals, staging index controls, structured business data, favicon work, mobile performance, tests, and draft treatment pages.

You are doing now

Connect the public site to Google and Bing, submit its sitemap, and check the website link and facts on the Google Business Profile.

You will do later

Review the favicon and any treatment wording in Wixy's draft preview, then press Publish only when you are happy.

Never submit the staging address

Everything in Google and Bing must use cottageaesthetics.co.uk. Do not add or submit ca.cinnamons.uk; that is the Wixy staging/admin host and is meant to stay out of search results.

Connect Google Search Console

Search Console is Google's private view of whether it has discovered, crawled, and indexed the site. Public Google searches are useful later, but this is the reliable place to diagnose a new domain.

Open Google Search Console Google's property guide

  1. Look for the property first

    Open the property selector at the top-left. If cottageaesthetics.co.uk is already listed, select it and skip to “Submit the sitemap”. Do not create a duplicate just because the dashboard is initially empty.

  2. If missing, add a Domain property

    1. In the property selector choose + Add property.
    2. Under Domain, enter only cottageaesthetics.co.uk — no https://, no www, and no slash.
    3. Select Continue.
    A verification record is already present

    The audit found this live DNS TXT record:

    google-site-verification=yLSyZnTI0wT5e2CGeoAuz34B7yVQvuvMkhm_ENvEf_o

    If Search Console verifies immediately, carry on. If it shows a different new token for this Google account, add the new TXT record alongside the existing one at the DNS provider. Do not delete or replace the existing record; it may prove ownership for another authorised user.

    If Google asks for a new DNS TXT record
    1. Copy the complete value Google gives you, including google-site-verification=.
    2. Sign in at Name.com, open cottageaesthetics.co.uk, then its DNS Records.
    3. Add a TXT record on the bare domain. Leave Host blank or use @, according to the form. Paste Google's full token as the value.
    4. Save it, wait for DNS to spread, then return to Search Console and select Verify. It can be quick, but waiting a few hours is normal.

  3. Submit the public sitemap

    1. Make sure the selected property is cottageaesthetics.co.uk.
    2. In the left menu open Sitemaps.
    3. Under Add a new sitemap, enter sitemap.xml. If the field expects a full URL, paste https://cottageaesthetics.co.uk/sitemap.xml.
    4. Select Submit.

    The first useful result is Success. The sitemap currently contains nine canonical pages, but the discovered count can take time to populate and need not appear instantly.

  4. Inspect and request the homepage

    1. Paste https://cottageaesthetics.co.uk/ into the inspection bar at the top of Search Console and press Enter.
    2. If it says the URL is not on Google or is unknown, choose Test live URL.
    3. The live result should say the URL is available to Google. Then select Request indexing.
    4. If it is already on Google and the last crawl is after the new-site cutover, no request is needed.
    One request is enough

    A successful request puts the page in a crawl queue; it does not guarantee indexing or make it immediate. Do not repeatedly submit the same unchanged page. The sitemap and normal internal links let Google find the other eight pages.

  5. Record the starting position

    Open Indexing → Pages. A new property can have little or no data for a while. Record what it shows rather than trying to force it.

Normal for a brand-new domain

Google says indexing new content can take a few days, and it does not promise to index every URL. The aim is for the canonical versions of the important pages to be indexed—not every duplicate address Google may discover.

Connect Bing Webmaster Tools

Bing can import the verified Google property and its sitemap. That is the simplest route and avoids adding another ownership file or DNS record.

Open Bing Webmaster Tools Bing's verification guide

  1. Import from Google Search Console

    1. Sign in to Bing Webmaster Tools with the Microsoft account you want to keep as the site owner.
    2. Choose Import sites from Google Search Console.
    3. When Google asks, sign in with the account that owns the Search Console property and allow Bing the requested read access.
    4. Select only the Cottage Aesthetics public property and choose Import.

  2. Confirm the sitemap

    1. Select the Cottage Aesthetics site, then open Sitemaps.
    2. The Google import may already have brought the sitemap across. If the full public sitemap is listed, do not add a duplicate.
    3. If it is missing, choose Submit sitemaps and paste https://cottageaesthetics.co.uk/sitemap.xml.

  3. Submit the homepage once if needed

    Use Bing's URL Inspection or URL Submission for https://cottageaesthetics.co.uk/ if Bing has not discovered it. There is no need to paste all nine URLs when the sitemap is healthy.

Leave IndexNow to the engineering lane

Bing recommends IndexNow for automated future updates, but it needs a deliberate publish integration and owner-controlled key. Do not paste unknown scripts or keys into the site. The Sonnet implementation lane will assess it separately; it is not required for today's nine-page sitemap.

Check the Google Business Profile

The profile is distinct from Search Console. It controls the business facts people see in Google Search and Maps. You must be signed into a Google account that owns or manages the verified profile.

    While signed into the managing account, search Google for Cottage Aesthetics Hartlebury. The owner controls should appear. Choose Edit profile. On a phone, the equivalent is Google Maps → Business → Edit profile.

Review the agent's work before Publish

Sonnet 5 can prepare the technical changes and content, but changes in the site repository remain on Wixy's draft side until the owner presses Publish. Do this review when the agent tells you the relevant PRs are merged and ready.

  1. Open the Wixy draft preview

    Use the normal Cottage Aesthetics Wixy admin. Review the homepage, gallery, contact page, and any new treatment pages on both a phone-sized view and a normal desktop view.

  2. Approve the favicon

    The agent should provide a visual sheet showing the proposed little browser/search icon at several sizes. It must still look recognisably Cottage Aesthetics at 16 px. Ask for a revision if it looks muddy, generic, or off-brand.

  3. Check every treatment claim

    For any new treatment page, confirm the treatment is actually offered and check every statement about suitability, expected result, duration, recovery, risks, products, prices, qualifications, and aftercare. Change or reject anything that is not exactly how the clinic works.

  4. Publish through Wixy—nowhere else

    When the draft is correct, press Publish in Wixy. Do not deploy the site repository's main branch directly. Wait a couple of minutes, then reload the public domain and check the changed pages there.

  5. Tell Google only about genuinely new or important changes

    After the public site is live, inspect the homepage again if its structured data or favicon changed. For each genuinely new treatment page, inspect its full public URL and request indexing once. The sitemap will update automatically; you do not need to delete and re-add it.

6

Check back later—without chasing it daily

Search engines work on their own schedules. Use these three sensible checkpoints.

After 48–72 hours

Check sitemap status and inspect the homepage. Note any explicit crawl or indexing error; low counts alone are not an emergency.

After 2 weeks

Review indexed pages, early queries/impressions, and Bing's index status. Share exact reasons for any important URL still excluded.

After 4 weeks

Compare impressions, clicks, branded searches, and treatment queries. Use this evidence to choose the next content work.

What to send back to the implementation agent

  • The exact wording of any Search Console or Bing error.
  • The affected public URL—not just a cropped warning.
  • The “last crawled” date and Google-selected canonical from URL Inspection.
  • A screenshot or CSV export of the Page indexing / Search performance table if several pages or queries are involved.
  • Never send passwords, one-time codes, backup codes, or full account access.

Troubleshooting

Search Console says the property is not verified

Check that you added a Domain property using only cottageaesthetics.co.uk. If Google generated a new TXT token for your account, add it alongside the existing token at Name.com; do not replace the old token. Wait for DNS propagation and try Verify again.

The sitemap says “Couldn't fetch”

Open the sitemap in a private browser window. It should show XML containing the public HTTPS domain. Confirm you selected the public property, submitted the exact URL, and did not use ca.cinnamons.uk. If the file opens normally, wait and retry later rather than repeatedly deleting and resubmitting it.

URL Inspection says “URL is unknown to Google”

Choose Test live URL. If the live result says it is available, choose Request indexing once. Discovery and indexing can still take days. If the live result reports a robots, fetch, server, canonical, or noindex problem on the public domain, send the exact result to the agent.

Search Console lists more than nine URLs

That is not automatically wrong. Google may know old Wix addresses, duplicate .html forms, redirects, and genuine 404s. The goal is for each important canonical page to be indexed. Export the list and reasons before asking the agent to change anything.

The Google Business Profile controls do not appear

You are probably signed into a Google account that is not an owner or manager of the profile. Switch accounts. If another person owns it, ask that owner to invite your Google account as an owner or manager—do not share a password.

A public Google result shows ca.cinnamons.uk

Copy the exact Google result URL and send it to the agent. Do not submit more staging URLs or remove the public property. The engineering work corrects staging's crawler signals; Search Console removal tools, if needed at all, should be used only with the exact staging URL and a deliberate plan.

What success looks like

Google and Bing accept the sitemap; the homepage becomes indexed; the Business Profile points at the correct domain; important canonical pages gradually appear; and real search queries begin producing impressions. There is no honest button or engineering change that guarantees a particular ranking.
